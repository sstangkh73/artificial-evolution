# Plan: เล่มรายงานฉบับเต็ม YSC 2027 (ร่าง .md)
Date: 2026-10-14

## Goal
ทำเล่มรายงานฉบับเต็มเหมือนเตรียมส่ง เป็นไฟล์ .md ฉบับร่างก่อนแปลงเป็น PDF
ผู้ใช้เลือกให้ใช้ผล pilot ในบทผล (ยังไม่รันยืนยัน) โดยติดป้ายชัดเจนว่าเป็นผล pilot และเว้นช่องไว้ให้ผลยืนยัน

## Context
- โครงเล่มตามคู่มือ YSC 2027 หน้า 101–104 มี 15 หัวข้อ: ปก, บทคัดย่อ, คำสำคัญ, สารบัญ, หลักการและเหตุผล, วัตถุประสงค์, สมมติฐาน, ประโยชน์, วัสดุอุปกรณ์, ระเบียบวิธี, ผลและวิเคราะห์, สรุป, กิตติกรรมประกาศ, การเปิดเผยการใช้ AI, บรรณานุกรม
- ปกต้องมีข้อความระบุทุน NSTDA/NRCT
- บทคัดย่อภาษาไทยไม่เกิน 350 คำ ภาษาอังกฤษไม่เกิน 250 คำ, คำสำคัญไม่เกิน 6 คำ คั่นด้วย ;
- แหล่งข้อมูล: ข้อเสนอ (`reports/YSC2027_emergent_tool_discovery_full_proposal.th.md` และ PDF ที่ส่งจริง), `docs/ysc2027_tool_discovery/00–05`, ข้อมูล pilot S1/S2

## Steps
1. สร้างกราฟ 3–4 รูปจากข้อมูล pilot S2 (`data/tool_discovery_pilot_s2_selected`)
2. เขียนเล่ม `reports/YSC2027_29YCSS00443_รายงานฉบับสมบูรณ์/รายงานฉบับสมบูรณ์_ร่าง.md`
3. ตรวจตัวเลขทุกตัวในเล่มเทียบกับ JSON/CSV และนับคำในบทคัดย่อ

## How it will be verified
สคริปต์ตรวจว่าตัวเลขในเล่มตรงกับไฟล์ JSON ของ pilot, นับคำบทคัดย่อ และเช็กว่ามีครบ 15 หัวข้อ

## Risks / assumptions
- ผลยืนยันยังไม่มี: ทุกตัวเลขผลมาจาก pilot และต้องติดป้ายเสมอ ห้ามเขียนเหมือนเป็นข้อสรุป
- การเปิดเผยการใช้ AI ต้องเขียนตามจริง: โค้ด การวิเคราะห์ และร่างเอกสารทำด้วย Claude Code และ OpenAI Codex ภายใต้การกำกับของนักเรียน
- ใช้ภาษาไทยเชิงวิชาการแบบเรียบง่าย ตามสไตล์ที่ผู้ใช้ต้องการ
