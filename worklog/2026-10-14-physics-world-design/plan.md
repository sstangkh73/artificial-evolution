# Plan: ออกแบบโลกฟิสิกส์การแตก (แทนโลกสูตร) + พิสูจน์ความเร็ว
Date: 2026-10-14

## เหตุผล
โลกเดิมคำนวณความคมจากสูตรสัดส่วนวัสดุ (`sharpness = หิน×3 + …`) ซึ่งเท่ากับผู้ออกแบบเขียนคำตอบไว้ในโลก
ผู้ใช้ตัดสินใจ (14 ต.ค.) ให้ใช้ฟิสิกส์การแตกแทนการทดลองหลัก โดยใช้ 2D เป็นหลักและออกแบบให้รองรับ 3D ตั้งแต่แรก

## ขั้นตอน
1. ต้นแบบ 2D: voxel → สามเหลี่ยม CST, FEM plane strain, การแตกแบบลบ element เมื่อ σ1 > σ_f = K_IC/√(π a0), แยกชิ้น, วัดมุมคม
2. ตรวจความถูกต้อง: เทียบกับคำตอบเชิงวิเคราะห์ (แท่งรับแรงดึง)
3. benchmark: เวลาต่อการตีหนึ่งครั้งที่ความละเอียด 32/48/64 + ดูว่ามุมตีเปลี่ยนมุมคมจริงหรือไม่
4. เอกสารออกแบบ `docs/physics_world/00_design.md`: สมการ, ค่าคงที่ (ต้องมีแหล่งอ้างอิง), สิ่งที่นำมาจาก Formula Ultimate, งบเวลา, ความเสี่ยง
