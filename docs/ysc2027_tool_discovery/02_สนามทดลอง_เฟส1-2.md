# เฟส 1–2: สนามทดลองค้นพบเครื่องมือ (tool-discovery arena)

จัดทำ: 14 ต.ค. 2569 · โค้ด: `simulation/tool_discovery.py`, `simulation/tool_discovery_metrics.py`, `scripts/run_tool_discovery.py` · เทสต์: `tests/test_tool_discovery.py`

## 1. โลก (ตามข้อเสนอ 3.2)
- ใช้กริด 40×40 จาก `Environment` เดิม (เขตปลอดภัย / เขตอันตราย และชนิดพื้นดิน)
- ประชากรผู้ใหญ่คงที่ 20 ตัว ไม่มีการสืบพันธุ์ ตายเมื่อพลังงานหมด และการตายนับเป็นผลการทดลอง
- เอเจนต์เดินแบบ random walk ด้วยลำดับสุ่มที่ผูกกับ seed ทุกเงื่อนไขจึงเดินเส้นทางเดียวกันและเจออาหารชุดเดียวกัน (paired seeds) คำถามวิจัยจึงอยู่ที่ "สร้างอะไร ใช้อย่างไร" ไม่ใช่การนำทาง
- ในแต่ละ tick ถ้าเจออาหาร (พืช / สัตว์ / อาหารใต้ดิน) เอเจนต์จะเลือกใช้มือเปล่า หรือใช้วัตถุที่ถืออยู่ด้วยการกระทำพื้นฐานหนึ่งแบบ
  ถ้าไม่เจออาหาร ทุกเงื่อนไขใช้กฎเดียวกัน คือสร้างวัตถุถ้ามีวัสดุพอและมีที่ว่าง ถ้าไม่ได้ก็เก็บวัสดุ
  สิ่งที่ต่างกันระหว่างเงื่อนไขมีแค่ "เลือกส่วนผสมไหน ใช้วัตถุชิ้นไหนกับการกระทำใด และทิ้งชิ้นไหน"

## 2. กฎของโลก (ซ่อนจากเอเจนต์)
- อาหารที่ได้ = ผลจากมือเปล่า + (ผลสำเร็จ + ⌊(คะแนน − เกณฑ์)/3⌋ ถ้าคะแนนวัตถุ ≥ เกณฑ์ของบริบทนั้น)
- คะแนนวัตถุมาจาก `score_object_for_action` เดิม และขึ้นกับความคม ความแข็ง ความยาว มวล บริบท และการกระทำ
- ต้นทุน: การใช้วัตถุ = 0.5 + 0.25 × มวล, การสร้าง = 2 ต่อวัสดุ, การเก็บวัสดุ = 1, การเผาผลาญ = 0.3 ต่อ tick
- วัตถุสึกหรอทุกครั้งที่ใช้ และแตกเมื่อความทนทานเหลือ 0 จึงต้องสร้างใหม่ ซึ่งเปิดโอกาสให้วัดการสร้างซ้ำ
- จากส่วนผสม 322 แบบ มีเพียง 11–14% ที่ผ่านเกณฑ์ของแต่ละบริบท (พืช 12, สัตว์ 14, ใต้ดิน 10) การค้นพบจึงไม่ใช่เรื่องบังเอิญง่าย ๆ

## 3. เงื่อนไข
| รหัส | กลไก |
|---|---|
| C0 | สุ่มทุกการตัดสินใจ ไม่มีหน่วยความจำ |

## 4. ตัวชี้วัด (ตามข้อเสนอ 3.4–3.5) ใน `summarize_run`
- หลัก: `final_net_per_alive_tick` คืออาหารสุทธิต่อ tick ที่ยังมีชีวิต ในช่วง 25% สุดท้ายของรัน พร้อมรายงานองค์ประกอบ (อาหาร แรง ต้นทุนการสร้าง ต้นทุนการเก็บ)
- ระดับ A: วัตถุถูกใช้ ≥ 3 ครั้ง ผลเฉลี่ยสูงกว่ามือเปล่าในบริบทเดียวกัน และมีอย่างน้อย 2 ครั้งที่สูงกว่า (ไม่ใช่โชคครั้งเดียว)
- ระดับ B: ผ่านระดับ A + เลือกใช้กลุ่มสมบัติเดิมซ้ำหลังได้ผลดีมากกว่าหลังได้ผลเสีย + สร้างกลุ่มสมบัติของวัตถุที่ผ่านระดับ A ซ้ำอย่างน้อย 1 ครั้ง
- รอง: เวลาถึงการค้นพบครั้งแรก (censored ถ้าไม่พบ), จำนวนวัตถุ, ความหลากหลายของกลุ่มสมบัติ, อัตราการใช้เครื่องมือ, learning gain (ช่วงท้ายลบช่วงแรก), ผู้รอดชีวิต
- ความกว้างของกลุ่มสมบัติ (`bin_width`) วิเคราะห์ใหม่จากข้อมูลดิบได้ (robustness ตามข้อเสนอ 3.9.4)

## 6. ปัญหาที่ pilot (เฟส 3) ต้องตัดสินก่อนตรึง protocol
1. **survivor bias ในตัวชี้วัดหลัก**: C0 ตายมาก ตัวที่เหลือจึงเป็นตัวที่โชคดี ทำให้ learning gain ของ C0 (0.46) สูงกว่า C1 ซึ่งไม่สมเหตุผล
   ต้องเลือกระหว่าง (ก) ลดอัตราตายจนเกือบทุกตัวรอดในทุกเงื่อนไข หรือ (ข) ใช้ตัวหารเป็น agent-slot (ตัวที่ตายนับเป็น 0) เป็นตัวชี้วัดหลัก แล้วรายงานอีกแบบเป็นตัวชี้วัดรอง
   ปัญหานี้ตรงกับ "survival selection artifact" ที่ Gate C ระบุไว้
2. **ระดับ A ผ่านทุกเงื่อนไข** แม้แต่ C0 เกณฑ์จึงหลวมเกินจะแยกกลุ่มได้ ต้องตัดสินว่าจะเพิ่มจำนวนครั้งขั้นต่ำ หรือให้ระดับ A เป็นตัวชี้วัดเชิงพรรณนา
3. **learner ใช้เครื่องมือน้อย** (11% เทียบกับ oracle 34%) คอขวดน่าจะอยู่ที่การสำรวจ ต้องเลือก ε, softmax, q_init และจำนวน tick โดยใช้เฉพาะ pilot seeds
4. ทุกค่าที่เลือกจะถูกตรึงใน protocol ก่อนรัน seeds ยืนยัน (5000+) ส่วน seeds 0–99 ถูกใช้ใน smoke/calibration แล้ว
