# 02 ข้อกำหนดฟิสิกส์ของแพ็กเกจ `lithics` (physics-loop รอบ 1)

เอกสารนี้บันทึกสมการ สูตร แหล่งอ้างอิง และสมมติฐานของแต่ละส่วน เขียนเพิ่มทีละส่วนตามขั้นใน `worklog/2026-10-15-physics-loop-r1/plan.md` ค่าที่ไม่มีแหล่งอ้างอิงจะเขียนว่า **สมมติฐาน** กำกับไว้

## 1. วัสดุและก้อนหิน (`lithics/materials.py`, `lithics/stone.py`)
- ค่าวัสดุทั้งหมดอ่านจาก `physics-loop/spec/materials.json` ไม่มีค่าตั้งในโค้ด
- G_c = K_IC²/E′ (Irwin; Anderson 2017, *Fracture Mechanics*, 4th ed., ch. 2) โดย E′ = E/(1−ν²) สำหรับ plane strain และ axisymmetric/3D และ E′ = E สำหรับ plane stress `Material.g_c` ใช้ค่า plane strain เพราะ K_IC ในตารางวัดภายใต้ plane strain ถ้าส่วนใดใช้ plane stress ต้องคำนวณ E′ ตามโหมดนั้น
- ก้อนหินคือกริดเซลล์สี่เหลี่ยมจัตุรัสขนาด h (2D) หรือลูกบาศก์ (3D) แต่ละเซลล์เก็บเลข phase
- **สมมติฐาน 1.1:** แร่แต่ละชนิดใน mosaic ของแกรนิตใช้ความหนาแน่นและ K_IC ของแกรนิตทั้งก้อน เพราะ spec ให้ค่ารายแร่แค่ E, ν และกำลังรับแรงดึง
- **สมมติฐาน 1.2:** จำนวนเม็ดแร่ของ Voronoi mosaic = ปริมาตรกล่องล้อมรอบ / grain_size^dim จุดศูนย์กลางเม็ดแร่สุ่มแบบสม่ำเสมอจาก seed ที่ระบุ และชนิดแร่สุ่มตามสัดส่วนปริมาตรใน spec

## 2. solver ยืดหยุ่นเชิงเส้น 2D (`lithics/fem2d.py`)

### 2.1 สมการและการแบ่ง element
- สมดุลสถิตของวัตถุยืดหยุ่นเชิงเส้น isotropic: ∇·σ = 0, σ = D ε, ε = ½(∇u + ∇uᵀ)
- ใช้ไฟไนต์เอลิเมนต์แบบ isoparametric quadrilateral 4 จุด (Q4) อินทิเกรตด้วย Gauss 2×2 (Hughes 1987, *The Finite Element Method*, ch. 3) เซลล์ที่มีเนื้อหิน 1 เซลล์ = 1 element ส่วน `quad_mesh` รับ mesh รูปสี่เหลี่ยมใด ๆ ไว้ตรวจสูตร element บนรูปทรงที่ไม่ติดกริด
- 3 โหมด:
  - `plane_strain`: ε_zz = 0, D = E/((1+ν)(1−2ν)) [[1−ν, ν, 0], [ν, 1−ν, 0], [0, 0, (1−2ν)/2]] ความหนานอกระนาบ = `Stone.thickness_m`
  - `plane_stress`: σ_zz = 0, D = E/(1−ν²) [[1, ν, 0], [ν, 1, 0], [0, 0, (1−ν)/2]]
  - `axisymmetric`: แกน x คือรัศมี r ≥ 0 แกน y คือแกนสมมาตร z ความเครียดมี 4 ตัว (ε_r, ε_z, ε_θ = u_r/r, γ_rz) อินทิเกรตรอบวงเต็ม (น้ำหนัก 2πr) จึงได้แรงเป็นแรงรวมทั้งวง และบังคับ u_r = 0 บนแกนให้อัตโนมัติ (Zienkiewicz & Taylor 2000, *The Finite Element Method* vol. 1, ch. 4)
- ประกอบเมทริกซ์ความแข็งแบบ vectorized ด้วย `numpy.einsum` แล้วเก็บแบบ sparse (CSR) แก้ระบบด้วย `scipy.sparse.linalg.spsolve` (direct solver ไม่มีค่าสุ่ม จึงคาดว่ารันซ้ำในเครื่องและ environment เดียวกันจะได้ผลเท่าเดิม แต่ข้ามเครื่องหรือข้ามเวอร์ชันของ BLAS อาจต่างกันระดับ floating point การรันซ้ำจะตรวจจริงใน V10)
- แรงจาก traction บนขอบคำนวณแบบ consistent (shape function เชิงเส้นบนขอบ Gauss 2 จุด)
- ความเค้นรายงานที่จุดกลาง element เป็น (σ_xx, σ_yy, σ_zz, σ_xy) โดย σ_zz คือความเค้นนอกระนาบ (ใน axisymmetric คือ hoop stress σ_θ)
- `stiffness_scale` คูณความแข็งราย element เตรียมไว้ให้แบบจำลองการแตก (ขั้น 3) ใช้ลดความแข็งของเนื้อที่แตกแล้ว

### 2.2 ผลตรวจเชิงวิเคราะห์ (`tests/lithics/test_lithics_fem2d.py`)
ใช้ค่าแก้ว soda-lime จาก spec ทุกกรณี

| กรณี | คำตอบเชิงวิเคราะห์ | ผล |
|---|---|---|
| แท่งรับแรงดึง plane strain และ plane stress | ε_xx = σ(1−ν²)/E หรือ σ/E | คลาดไม่เกิน 1e-8 (สนามเชิงเส้น Q4 ให้คำตอบแม่นตรง) |
| ทรงกระบอกตันรับแรงดึงตามแกน (axisymmetric) | ε_zz = σ/E, u_r = −νσr/E | คลาดไม่เกิน 1e-8 |
| ทรงกระบอกหนารับความดันภายใน (Lamé, ε_z = 0) | u_r = pa²(1+ν)/(E(b²−a²))·((1−2ν)r + b²/r) (Timoshenko & Goodier 1970, *Theory of Elasticity*, §28) | u_r คลาด < 0.5%, σ_θ คลาด < 2% |
| patch test บน quad บิดเบี้ยว | สนามเชิงเส้นต้องได้ความเค้นคงที่แม่นตรง | คลาดไม่เกิน 1e-8 |
| แท่งสองวัสดุต่ออนุกรม (แร่ 2 ชนิดของแกรนิต, plane stress) | แต่ละส่วนยืด σL/E_k | คลาดไม่เกิน 1e-8 |
| แผ่นมีรูวงกลม (Kirsch 1898) mesh แนบรูปทรงแบบเชิงขั้ว | σ_max = 3σ ที่ขอบรู | SCF = 3.005 (60×48 element, คลาด 0.2%) ทั้ง plane strain และ plane stress, error ลดลงทุกครั้งที่ mesh ละเอียดขึ้น (20, 40, 80 วง) |
| โปรไฟล์ความเค้นของ Kirsch ที่ r = 1.1a–3a, θ ≈ 0 | σ_yy/σ = 1 + a²/(2r²) + 3a⁴/(2r⁴) | คลาด < 3% ทุกจุด (ตรวจโดยไม่ต้องประมาณค่านอกช่วง) |

วิธีวัด SCF: นำ σ_yy ที่จุดกลางของ element 3 วงแรกในแนว θ ≈ 0 มาฟิตพหุนามกำลังสองตามระยะ r−a แล้วประมาณค่าที่ r = a พหุนามดีกรี 2 ผ่าน 3 จุดพอดี การประมาณนี้จึงไม่มีจุดตรวจของตัวเอง จึงเพิ่มการเทียบโปรไฟล์ความเค้นในแถวถัดไปเป็นหลักฐานอิสระ ขอบนอกอยู่ที่ R = 25a และรับ traction σ·n สม่ำเสมอ จึงยังไม่ใช่แผ่นอนันต์จริง พจน์ (a/R)² ของ Kirsch มีขนาดประมาณ 0.16% นอกจากนี้ขอบรูใน mesh เป็นรูปหลายเหลี่ยม 48 ด้านต่อหนึ่งในสี่วง ไม่ใช่วงกลมแท้ ผลที่วัดจึงรวม error จากการประมาณรูปทรงนี้ด้วย ซึ่งเล็กมากเมื่อเทียบกับเกณฑ์ 5%

### 2.3 ข้อจำกัดที่พบ: ขอบโค้งแบบขั้นบันไดบนกริดเซลล์
- เมื่อทำรูวงกลมด้วยเซลล์สี่เหลี่ยม (ขอบเป็นขั้นบันได) วิธีวัดเดียวกันให้ SCF = 2.55 ที่รัศมีรู 16 เซลล์ และ 2.64 ที่ 24 เซลล์ คือต่ำกว่า 3 อยู่ 12–15% และลู่เข้าช้า (ทดลองเมื่อ 2026-10-15 ด้วย plane strain แผ่นกว้าง 10a)
- ความคลาดนี้มาจากการแทนรูปทรงโค้งด้วยขั้นบันได ไม่ได้มาจากสูตร element เพราะ mesh แนบรูปทรงให้ผลถูกต้อง
- ผลกระทบต่องานต่อไป: ความเค้นบนผิวโค้งของก้อนหินที่ทำจากเซลล์จะคลาดได้ระดับ 10% ส่วนผิวเรียบที่ตรงกับแนวกริด เช่น แท่นตี ไม่มีปัญหานี้ ขั้น 6 (mesh convergence) และรายงาน 03 ต้องรายงานผลนี้ด้วย
- V11 `kirsch_scf_rel_error` จึงวัดบน mesh แนบรูปทรง เพื่อตรวจ solver ส่วนผลบนกริดเซลล์จะรายงานคู่กันเป็นข้อมูลเพิ่ม ไม่นำมาตัดสิน
