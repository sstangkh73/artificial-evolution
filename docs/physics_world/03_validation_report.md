**เกณฑ์ที่ตั้งไว้ก่อนรัน (รอบ 46 ร่วมกับ Codex):** จำนวนชิ้นเท่าเดิม พื้นที่ชิ้นต่างกัน ≤ 5% และพลังงานแตกต่างกัน ≤ 5% เมื่อเปลี่ยน n → 2n → 4n และ tol ครึ่งหนึ่ง และทุกขั้นต้องลู่เข้า

**ผล:**
- กรณีหินรอง: ไม่ผ่าน ค่า κ ที่ทดสอบ (0.1 และ 1; κ = 0 คือปัญหาเดิมของรอบ 44) ไม่ทำให้ทุกขั้นลู่เข้า (ไม่ได้ทดสอบ κ = 0.01 บนหินรอง) และเวลา 204–358 วินาทีต่อการตีเกินเกณฑ์ V9 (≤ 60 วินาที) อยู่แล้ว ความหนืดเพิ่มเวลา (κ = 1 ช้ากว่า κ = 0.1) แทนที่จะช่วย เมื่อเพิ่ม n_steps จาก 10 เป็น 20 (κ = 1) จำนวนชิ้นเปลี่ยนจาก 3 เป็น 4 และชิ้นที่สองเล็กลง 11% (563 → 503 เซลล์) จึงไม่ผ่านเกณฑ์ load-step ส่วน tol ครึ่งหนึ่งให้ผลเหมือนเดิมทุกตัวเลข ซึ่งเป็นเพราะขั้นที่ไม่ลู่เข้าหยุดที่จำนวนรอบสูงสุด (tol ไม่มีผล) ไม่ใช่หลักฐานความคงที่ ผลชิ้นที่ได้จากขั้นที่ไม่ลู่เข้าจึงไม่ใช่คำตอบที่นิยามชัด แม้ตัวเลขชิ้นของ κ = 1 และ 0.1 จะใกล้กัน
- กรณีมือ: ผ่านเกณฑ์ sensitivity ที่ตั้งไว้ (ยังไม่ใช่ผล V ทางการ) จำนวนชิ้นคงที่ (2) ทุกค่า κ, n_steps และ tol ที่ทดสอบ ชิ้นเล็กมี 325–335 เซลล์ในทุกการรัน (ต่างกันไม่เกิน 3.1%) พลังงานแตกเมื่อเปลี่ยน n_steps/tol ที่ κ คงที่ต่างกันไม่เกิน 3.6% (κ = 1: 0.0398–0.0413 mJ; κ = 0: 0.0387–0.0396 mJ) แต่ถ้ารวมการเปลี่ยน κ ด้วยต่างกันถึง 6.7% (0.0387–0.0413 mJ) ทุกขั้นลู่เข้า และใช้เวลา < 4 วินาที ความหนืดไม่จำเป็นสำหรับกรณีนี้ (κ = 0 ให้ผลในเกณฑ์เดียวกัน)

**การตีความ (สมมติฐาน ยังไม่ได้พิสูจน์):** ความเห็นที่สองของ Codex (รอบ 46) ชี้ว่าต้นเหตุน่าจะเป็นแบบ hybrid ที่ไม่ใช่การหาค่าต่ำสุดของพลังงานเดียว (ขั้น u ใช้ ψ ทั้งหมด ขั้น d ใช้ ψ⁺) เมื่อรวมกับข้อจำกัดสัมผัสสองด้าน (ค้อนและหินรอง) การวนรอบ staggered จึงไม่มีฟังก์ชันพลังงานที่ลดลงทุกรอบเป็นตัวรับประกันการลู่เข้า ส่วนกรณีมือมีข้อจำกัดสัมผัสด้านเดียวและก้อนเคลื่อนได้อิสระ (inertia relief) ร้าวจึงปลดแรงได้ทันที ความหนืดของ Miehe ทำให้การวิ่งของร้าวช้าลงตามเวลาเทียม แต่ในแบบจำลองนี้เวลาเทียมเป็นขั้นโหลด ไม่ใช่เวลาจริง จึงไม่แก้การไม่ลู่เข้าภายในขั้น

**การตัดสิน (ตามคำตัดสินของผู้ใช้ 2026-10-16 ใน `worklog/2026-10-15-physics-loop-r1/plan.md`):**
- ใช้การตีแบบถือในมือเป็นกรณีหลักของ V2, V3, V6 และ V9 การเลือกนี้มาจากผลการลู่เข้าเชิงตัวเลขข้างบนเท่านั้น ไม่ได้ดูผล V1–V5
- การตีบนหินรองเป็น**ข้อจำกัดที่ประกาศไว้**: รายงานผลเท่าที่มีโดยไม่ใช้เป็นหลักฐานของเกณฑ์ใด และห้ามใช้ผลจากขั้นที่ไม่ลู่เข้าหรือขั้นที่ใช้ทางสำรอง monotone เป็นผลวัด
- ไม่ลดเกณฑ์ V ข้อใด และไม่ใส่ viscous regularization ลงใน `lithics/` (ไม่ช่วยกรณีหินรอง และไม่จำเป็นในกรณีมือ จึงไม่เพิ่มพารามิเตอร์เชิงตัวเลขที่ไม่มีประโยชน์)
- ผลต่อโลกของเอเจนต์ (รอบ 2): การตีบนหินรอง (bipolar) ยังไม่ควรเปิดให้เอเจนต์ใช้จนกว่าจะมีแบบจำลองที่ลู่เข้า เช่น แบบพลวัต (explicit dynamics) หรือแบบ variational ที่มีข้อจำกัดสัมผัสอยู่ในพลังงานเดียว ซึ่งอยู่นอกขอบเขตรอบนี้
