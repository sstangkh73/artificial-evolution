## ชื่อเรื่องชั่วคราว

**When Does a Better Representation Pay? Survival Effects of Resource-Age Information in Artificial Foraging Under Temporal Toxicity**

ชื่อไทยสำหรับใช้อธิบายงาน:

**เมื่อไร representation ที่ดีกว่าจึงคุ้ม: ผลของข้อมูลอายุอาหารต่อการอยู่รอดของตัวหาอาหารเทียมภายใต้พิษที่เปลี่ยนตามเวลา**

## คำถามหลัก

ข้อมูลอายุอาหารช่วยให้ตัวหาอาหารเทียมแยกช่วงปลอดภัยออกจากช่วงเป็นพิษได้ แต่การแยกได้ดีขึ้นช่วยให้อยู่รอดมากเพียงใด และผลนั้นเปลี่ยนอย่างไรเมื่ออาหารเสี่ยงมีค่าพลังงานต่างกัน?

## ข้อเสนอหลักของเปเปอร์

งานนี้แยกคำถามสองข้อที่มักถูกรวมกัน:

1. **ข้อมูลช่วยให้ตัดสินใจถูกหรือไม่** — E2 แสดงเชิงสาเหตุว่า cue อายุทำให้แยกพิษได้ เพราะข้อมูลในคีย์ ไม่ใช่เพราะเพิ่มจำนวนคีย์หรือการสำรวจ
2. **การตัดสินใจที่ถูกนั้นคุ้มค่าหรือไม่** — ที่ค่าพลังงานปัจจุบัน การแยกพิษแทบไม่เพิ่มอายุขัย และการหลบพิษทั้งหมดทำให้อายุสั้นลง เพราะผลไม้ที่มีพิษยังเป็นอาหารที่มีค่าที่สุด

E6 พบ positive slope ตามเกณฑ์ที่ลงทะเบียนไว้ แต่รูปแบบระดับย่อยแสดงว่าไม่ตรวจพบต้นทุนของ representation ที่มีข้อมูลอายุที่พลังงาน 10 และ sensitivity ชี้ว่า slope ขึ้นกับ endpoint นี้ ส่วน T2-RB ยืนยันว่า age-varying toxicity ลดเวลาอยู่รอดเทียบ constant-potency control ทั้งสองนิยาม

ในต้นฉบับจะเรียกผลต่างนี้ว่า **survival effect of resource-age information** ซึ่งนิยามเชิงปฏิบัติการเป็นผลต่างอายุขัยระหว่าง B2 และ B3 ที่จับคู่ seed โดย resource age คืออายุของชิ้นอาหารตั้งแต่ถูกสร้าง ไม่ใช่อายุ agent ไม่เรียกว่า expected value of perfect information หรือ Darwinian fitness value เพราะ agent ไม่ได้ปรับนโยบายอย่างเหมาะที่สุดและ E-series ไม่มีการสืบพันธุ์

## ข้ออ้างที่ตัดออกจากต้นฉบับ

- ไม่เรียกปรากฏการณ์นี้ว่า ecological trap
- ไม่อ้างว่าความซ่อนเร้นของพิษสร้างต้นทุนเกินกว่าปริมาณพิษ
- ไม่อ้างว่าตัว agent ค้นพบ cue อายุ; ผู้ทดลองเป็นผู้ให้ cue นี้
- ไม่เรียก avoidance oracle ว่านโยบายที่เหมาะสมที่สุด
- ไม่อ้างวิวัฒนาการข้ามรุ่น เพราะยังไม่มีการเกิดในชุด E-series
- ไม่อ้างว่าการเก็บอาหารไว้ให้หายพิษเกิดขึ้นแล้ว

## แบบต้นฉบับ

วางเป็น **Article** ฉบับเดียวที่รวม controlled mechanism เดิมกับ full-ecology E1-E6 แทน Letter เดิมเรื่อง lure เพื่อให้ข้อเสนอใหม่ตั้งอยู่บนทั้งกลไก การกู้คืนเชิงสาเหตุ และผลด้านนิเวศ

โครงเรื่องหลัก:

1. type-level value learning รวมสถานะพิษที่ต่างกันไว้ในค่าเดียว
2. การให้ข้อมูลอายุแก้การแยกพิษได้ แม้โปรไฟล์พิษจะไม่เป็นเส้นเดียว
3. การแก้การแยกพิษไม่ได้รับประกันประโยชน์ด้านการอยู่รอด
4. ผลของข้อมูลต่อการอยู่รอดต้องวัดเทียบกับคุณค่าของทรัพยากรที่ข้อมูลนั้นเปลี่ยนการตอบสนอง
5. E6 ทดสอบความสัมพันธ์นี้โดยตรง

2. ตรวจและ freeze preregistration addendum: E6 30 seed และ T2 replication 50 seed พร้อม sample-size sensitivity analysis ก่อนเห็นผลชุดยืนยัน — **เสร็จแล้ว 2026-09-14; tag `prereg-resource-age-2026-09-14`**
3. รันและวิเคราะห์ชุดยืนยันแบบจับคู่ตาม seed รวม 600 รัน — **เสร็จแล้ว 600/600 รัน, 0 failure, validator ผ่านทั้งหมด**
4. สร้าง Figure 1-5 พร้อม source data — **เสร็จแล้ว 5 รูป ทั้ง PNG 300 dpi และ PDF พร้อมตาราง seed-level 8 ไฟล์**
5. ค้นและอ่านวรรณกรรมฉบับจริงเรื่อง value of information, state representation, partial observability และ foraging information use — **อ่านฉบับเต็มและผูก claim แล้ว 5 แหล่งหลัก; ยังเหลือ candidate sources ใน evidence matrix**
6. เขียน manuscript ภาษาอังกฤษใหม่; manuscript เดิมที่มี `lure/trap` ใช้เป็นแหล่งชิ้นส่วนเท่านั้น — **เติม Introduction, Methods และ Results จาก E1-E6/T2-RB พร้อม ODD ส่วนกลไกหลักแล้ว; ยังเหลือขยาย discussion, ตารางพารามิเตอร์ E1-E5 และตรวจถ้อยคำทั้งฉบับ**
7. ปิดงาน reproducibility, archive/DOI, license, AI disclosure และตรวจ reference ทุกชิ้น
8. ทำ ODD model description ให้ครบทุก state/parameter และให้บุคคลอื่นทำ clean-clone reproduction อย่างน้อยหนึ่ง seed ต่อแขนก่อนส่ง

## กฎกันการเลือกผลย้อนหลัง

- pilot E6 เป็น exploratory และไม่มีสิทธิ์ใช้ทดสอบสมมติฐานในเปเปอร์
- ทิศทาง P6.1-P6.3, ตัวแปรตาม, seed, exclusion rule และวิธีวิเคราะห์ต้องถูกตรึงก่อนรันยืนยัน
- ผลที่สวนสมมติฐานต้องรายงานตามทิศจริง
- หาก E6 ไม่ให้เส้นโค้งตามคำทำนาย ให้เขียนเป็น boundary/negative result ตามข้อมูล ไม่เปลี่ยนคำถามย้อนหลัง
