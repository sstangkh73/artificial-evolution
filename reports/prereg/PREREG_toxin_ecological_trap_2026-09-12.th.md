## 3. E1 — ต้นทุนของกับดักในนิเวศเต็ม

### 3.1 แขน

| แขน | ธงเพิ่มเติม | บทบาท |
|---|---|---|
| **A0** | `--toxin-potency-scale 0` | ฐาน **จับคู่อาหาร**: ผลไม้เกิดเท่ากัน แต่ไม่มีพิษ |
| **A1** | `--toxin-potency-scale 1` | พิษคงที่เต็มกำลัง — **อ่านออก เรียนรู้ได้** |
| **A2** | `--toxin-detox-ticks 120` | **แขนทดลอง** — พิษซ่อนในอายุอาหาร |
| **A3** | `--toxin-potency-scale 0.757811` | พิษคงที่ **จับคู่ dose กับ A2** — ไม่มีสถานะซ่อน |

> A0 **ไม่ใช่** "ไม่มีผลไม้พิษ" ตามแผนเดิม เพราะ `raw_fruit` ให้พลังงาน 10.34 เทียบอาหารหลัก 4.755 การเอามันออกคือการลดอาหาร ไม่ใช่ลดพิษ (E0 §3.1)

20 seed × 4 แขน = **80 รัน** (~25 นาทีที่ `--jobs 4`)

### 3.2 การทดสอบหลักที่ประกาศล่วงหน้า (3 รายการ, ปรับด้วย Holm)

| # | การเปรียบเทียบ | ตัวแปรตาม | ทิศทางที่ทำนาย | ปิดช่องว่าง |
|---|---|---|---|---|
| **T1** | A2 − A0 | อายุเฉลี่ยตอนตายของ founder cohort | **A2 < A0** | G1 |
| **T2** | A2 − A3 | อายุเฉลี่ยตอนตายของ founder cohort | **A2 < A3** (ตามสมมติฐานเดิม) | G1 (ชี้ขาด) |
| **T3** | A2 − A1 | `P(กิน \| เจอผลไม้)` | **A2 > A1** | G1/G3 |

**ค่า α รวม 0.05 ปรับด้วย Holm ข้ามสามรายการนี้เท่านั้น** การเปรียบเทียบอื่นทั้งหมดเป็นรอง ไม่มีการอ้างเชิงยืนยัน

> **ประกาศล่วงหน้าเรื่อง T2:** pilot 5 seed ให้ +4.17 tick (ทิศทางกลับด้าน), p = 0.31, Cliff's δ = +0.12
> เราคาดว่า **T2 จะไม่ถูกปฏิเสธ** และผูกมัดล่วงหน้าว่าถ้าเป็นเช่นนั้น จะเปลี่ยนกรอบตามจุดตัดสินใจ D2 ไม่ใช่หาทางอธิบายให้ผ่าน

| # | สมมติฐาน | คำทำนาย | หักล้างเมื่อ |
|---|---|---|---|

| **H1.2** | ความซ่อนเร้นสร้างต้นทุน **เกินกว่า** ปริมาณพิษ | T2: A2 < A3 | A2 ≥ A3 → **สมมติฐานกับดักเชิงนิเวศถูกหักล้าง** |

### 3.4 ตัวแปรตามรอง (รายงานทุกครั้ง ไม่ว่าผลจะออกมาอย่างไร)

`toxin_ingested_total` ต่อ agent และ **ต่อการเผชิญ** · `toxin_damage_total` · `damage` รวม · สัดส่วน `toxin_damage_total/damage` · การกระจาย `death_reason` (รวม `durability_depleted` ซึ่ง E0 พบ 4–11 ตัว/รัน) · จำนวนการเผชิญต่อ agent · `food_value_memory` ตอนจบ · จำนวนเกิด · `best_known` เฉลี่ยต่อแขน

### 3.5 confound ที่ต้องรายงานเสมอ

1. **จำนวนการเผชิญต่างกันมากระหว่างแขน** — E0 วัดได้ A0 31 · A3 34 · A2 44 · A1 74 ต่อ agent เพราะ agent ที่ปฏิเสธผลไม้ทิ้งมันไว้แล้วเจอซ้ำ → ทุกตัวแปรที่เป็น "จำนวน" ต้องหารด้วยการเผชิญ
2. สัดส่วนมื้อที่กินใต้เพดาน `diet_starvation_energy` (ความหิวบังคับกิน)
3. `best_known` ต่อแขน (เพดานของเกณฑ์ pickiness)
4. สัดส่วนการตายที่ไม่ใช่ความชราภาพ

## 4. E2 — แขนกู้คืน: ข้อมูลขั้นต่ำที่ทำให้หลุดจากกับดัก

### 4.1 แขน × โปรไฟล์

| แขน | `--food-value-key-mode` | บทบาท |
|---|---|---|
| B1 | `type` | เท่ากับ A2 ของ E1 |
| B2 | `type_age` | **แขนกู้คืน** — ได้ cue อายุครบ |
| B3 | `type_sham` | **ควบคุมจำนวนคีย์** — คีย์เท่ากัน ไม่มีข้อมูล |
| B4 | oracle (กฎตายตัว ไม่เรียนรู้) | เพดานบนทางทฤษฎี |

| โปรไฟล์ | ธง | เหตุผล |
|---|---|---|
| **M** เส้นตรง | `--toxin-detox-ticks 120` | "เก็บไว้นานพอ พิษจะจาง" |
| **W** หน้าต่าง | `--toxin-safe-window-start 40 --toxin-safe-window-end 80` | **พิษ → ปลอด → พิษ** ตัดคำอธิบาย "แก่กว่า = ปลอดกว่า" ทิ้งทั้งหมด |

20 seed × 4 แขน × 2 โปรไฟล์ = **160 รัน**

### 4.2 ตัวแปรตามหลัก

**ดัชนีการแยกแยะ** `D = P(กิน | เจอ, สถานะจริงปลอดภัย) − P(กิน | เจอ, สถานะจริงเป็นพิษ)`

นิยาม "ปลอดภัยจริง" ตรึงไว้ล่วงหน้า: **dose = 0** คือ `load × potency ≤ tolerance` โดย `load = 0.36`
→ ปลอดภัยเมื่อ `potency ≤ tolerance/0.36`; ที่ tolerance ฐาน 0.2 คือ `potency ≤ 0.5556` → **อายุ ≥ 54 tick** ในโปรไฟล์ M (bin การเผชิญ ≥ 11)

**การเปรียบเทียบหลัก: B2 − B3** (ทำนาย B2 > B3) — ทดสอบเดียว ไม่ปรับ multiplicity

### 4.3 สมมติฐาน

| # | สมมติฐาน | คำทำนาย | หักล้างเมื่อ |
|---|---|---|---|
| **H2.1** | cue อายุแก้ปัญหาได้ | D(B2) > 0 อย่างมีนัยสำคัญ ทั้ง M และ W | D(B2) ≈ 0 |
| **H2.2** | ผลไม่ได้มาจากการสำรวจที่มากขึ้น | D(B3) ≈ 0 ทั้งที่จำนวนคีย์เท่า B2 | D(B3) ≈ D(B2) → คำอธิบายคือการสำรวจ |
| **H2.3** | B1 แยกแยะไม่ได้ **โดยโครงสร้าง** | D(B1) = 0 | — (เป็นผลจากนิยาม ไม่ใช่การค้นพบเชิงสถิติ — **ต้องเขียนแบบนี้ในต้นฉบับ**) |
| **H2.4** | B2 ยังต่ำกว่าเพดาน | D(B4) > D(B2) | D(B2) ≥ D(B4) → สงสัยข้อมูลรั่ว ต้องตรวจ |

### 4.4 รูปหลักของเปเปอร์

แกน x = อายุอาหาร · เส้นทึบ = ความจริง (potency ตามอายุ) · เส้นประ = ค่าที่ agent เรียนรู้ · จุด/แท่ง = `P(กิน | อายุ)` ต่อแขน — รูปเดียวแสดง **ความจริง ความเชื่อ และการกระทำ**

## 5. E3 — แรงกดดันคัดเลือกบน `toxin_tolerance`

### 5.1 เงื่อนไขบังคับ

1. `--model v2` (ไม่งั้นยีนกลุ่ม metabolism ไม่ถ่ายทอด)
2. `--founder-toxin-tolerance-spread 0.15` — **ถ้าไม่มี ค่าของ founder เท่ากันหมดที่ 0.2 และ S = 0 โดยโครงสร้าง** (E0 ตรวจพบ)
3. `--aging --toxin-damage-coeff 5`

### 5.2 ระดับข้ออ้าง

| ระดับ | ตัวชี้วัด | สถานะ |
|---|---|---|
| **N1 selection differential** | `S = ค่าเฉลี่ย toxin_tolerance ของครึ่งบนที่อายุยืนที่สุด − ค่าเฉลี่ยของ founder ทั้งหมด` และ `cov(toxin_tolerance, อายุตอนตาย)` | **เป้าหมาย** |
| **N2 response to selection** | `mean_toxin_tolerance` ต่อรุ่น | **ถูกปิดกั้น** — E0 พบว่าไม่มีการเกิดเลย (births = 0) |

**N2 จะถูกรายงานว่าถูกปิดกั้น** พร้อมอ้าง `research_summary_2026-06-30.en.md` ไม่ใช่ถูกเงียบ

### 5.3 สมมติฐาน (แขน A0 / A2 / A3 ของ E1, เพิ่ม `--founder-toxin-tolerance-spread 0.15`)

| # | สมมติฐาน | คำทำนาย | หักล้างเมื่อ |
|---|---|---|---|
| **H3.1** | พิษสร้างแรงคัดเลือกบวกต่อความทนพิษ | S(A2) > S(A0) | S(A2) ≈ S(A0) |
| **H3.2** | พิษที่ซ่อนสร้างแรงคัดเลือก **แรงกว่า** พิษคงที่ปริมาณเท่ากัน | S(A2) > S(A3) | S(A2) ≤ S(A3) |
| **H3.3** | A0 ไม่แสดงแรงคัดเลือก (control ของ drift) | S(A0) ไม่ต่างจาก 0 | S(A0) ≠ 0 → มี drift/confound |

**การเปรียบเทียบหลัก: S(A2) − S(A0)**

ถ้า S ≈ 0 ทุกแขน: รายงานเป็นผลลบ พร้อมสัดส่วน `toxin_damage_total/damage` (E0 วัดได้ 12–24%) เพื่อแสดงว่าพิษเป็นสาเหตุการตายสัดส่วนเท่าไร

## 6. E5 — ทำซ้ำใน regime ที่สอง

รัน **A0, A2, A3** ที่ `--drain-mult 0.5` × 20 seed = **60 รัน**
(แผนเดิมระบุ A2/A3 เท่านั้น แต่ E0 แสดงว่า A0 คือ control ที่ข้ออ้าง G1 ตั้งอยู่บนมัน จึงต้องมีด้วย)

**คำทำนายที่ประกาศล่วงหน้า:** กับดักควร **อ่อนลง** ใน R-B เพราะเพดาน `diet_starvation_energy` บังคับให้กินอยู่แล้ว
ถ้าผลกลับด้าน ต้องอธิบายเชิงกลไก ไม่ใช่เงียบ

*สัญญาณเบื้องต้นจาก E0 (1 seed):* ต้นทุน A2 เทียบ A0 คือ −61.2 tick ที่ drain 0.5 และ −49.5 ที่ drain 0.2 → อาจ **ไม่** อ่อนลง ถือเป็นคำเตือนว่าคำทำนายนี้อาจผิด

## 7. วิธีทางสถิติ (ตรึง)

1. คำนวณเมตริกระดับ run ก่อน (เฉลี่ยข้าม agent ภายใน run) แล้วจึงวิเคราะห์ข้าม run
2. ผลต่างจับคู่ต่อ seed: `D_i = metric(แขนซ้าย, seed i) − metric(แขนขวา, seed i)`
3. รายงานทุกครั้ง: ค่าเฉลี่ย/SD/มัธยฐานต่อแขน · ค่าเฉลี่ยผลต่างจับคู่ · **CI 95% แบบ t และแบบ bootstrap** · **exact two-sided sign-flip test** (แจงนับครบ 2²⁰ ที่ n = 20) · **Cliff's delta** · จำนวน seed ที่ไปแต่ละทิศทาง
4. multiplicity: Holm ข้าม T1–T3 ของ E1 เท่านั้น · การเปรียบเทียบหลักของ E2/E3/E5 เป็นการทดสอบเดี่ยว · การเปรียบเทียบรองปรับ Holm ภายในกลุ่มรอง และ **ห้ามใช้อ้างเชิงยืนยัน**
5. **ห้ามใช้ Mann–Whitney แบบไม่จับคู่เป็นหลักฐานหลัก** (บทเรียนจากการแก้ p-value ใน `EVIDENCE.md`)
6. เครื่องมือ: `scripts/analyze_e_series.py` (ตรวจแล้วว่าการแจงนับ Gray-code ตรงกับการแจงนับตรงไปตรงมาที่ n = 12)

## 9. สิ่งที่ห้ามอ้างไม่ว่าผลจะออกมาอย่างไร

คัดลอกลงส่วน Limitations ของต้นฉบับ:

1. ✗ agent **เข้าใจ**ว่าอาหารเป็นพิษ — มีแค่ตัวเลขจากประสบการณ์
2. ✗ agent **ค้นพบ**ว่าอายุสำคัญ — ในแขน B2 เราเป็นคนใส่ cue ให้ (เป็นเพดานบนทางทฤษฎี)
3. ✗ การถ่ายทอดความรู้ทางสังคม — เป็นการเรียนรู้ส่วนบุคคลล้วน
4. ✗ กฎการเรียนรู้วิวัฒน์ขึ้นเอง — ตรึงไว้ทุกแขน
5. ✗ การเก็บ/เลื่อนการกิน (G6) — ไม่ได้ implement
6. ✗ วิวัฒนาการแบบเปิดปลาย หรือประชากรยั่งยืนข้ามรุ่น — **births = 0 ในทุกรันของ E0**
7. ✗ ความสอดคล้องเชิงปริมาณกับสัตว์จริง — ขอบเขต `p*` ผูกกับค่าพลังงานที่เราเลือก
8. ✗ ว่า `--drain-mult 0.2` เป็นค่าธรรมชาติ — เราเลือกเพื่อให้ความชราภาพเป็นสาเหตุการตายหลัก
9. ✗ ว่าความแปรผันของ `toxin_tolerance` ใน E3 เกิดขึ้นเอง — **เราใส่ให้ด้วย `--founder-toxin-tolerance-spread`**
