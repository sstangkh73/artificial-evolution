# รายการที่ต้องตรวจและแนบก่อนส่ง YSC 2027

เอกสารข้อเสนอโครงการรหัส `29YCSS00443` จัดทำจากรายงานภายในและวางลงโครงสร้างแบบฟอร์มทางการแล้ว รายการต่อไปนี้ต้องดำเนินการโดยผู้พัฒนา อาจารย์ที่ปรึกษา ผู้ปกครอง และโรงเรียนก่อนอัปโหลดจริง

## ตรวจข้อมูลในข้อเสนอ

- [ ] ผู้พัฒนาตรวจชื่อไทย/อังกฤษ ชื่อโรงเรียน ระดับชั้น และชื่อโครงการเดิม
- [ ] อาจารย์ที่ปรึกษาตรวจชื่ออังกฤษ `Bhopit Mangkala`, วุฒิ `ค.บ. คอมพิวเตอร์ศึกษา` และคำอธิบายความเชี่ยวชาญ
- [ ] ผู้พัฒนาและอาจารย์ที่ปรึกษาตรวจว่าบทสรุป วัตถุประสงค์ สมมติฐาน วิธีทดลอง และแผน 14 สัปดาห์ตรงกับสิ่งที่จะทำจริง
- [ ] ตรวจข้อความเปิดเผยการใช้ OpenAI Codex และเก็บบัญชีที่มา/ประวัติคำสั่งไว้ในสมุดบันทึก
- [ ] ตรวจ PDF ทุกหน้าอีกครั้งหลังมีการแก้ไขหรือสแกนเอกสารเพิ่ม

## ลายมือชื่อและแบบฟอร์ม

- [ ] พิมพ์และลงนามหน้าปก SIMS ให้ครบทุกช่องที่ระบบกำหนด
- [ ] แบบฟอร์ม 1 จำนวน 1 ฉบับต่อโครงการ
- [ ] แบบฟอร์ม 1A จำนวน 1 ฉบับต่อโครงการ
- [ ] แบบฟอร์ม 1B ของผู้พัฒนา โดยกรอกเฉพาะส่วนที่ 1 และให้ผู้ปกครองลงนาม
- [ ] แบบฟอร์ม 6 สำหรับโครงการต่อเนื่อง พร้อมอธิบายงานเดิมและงานใหม่ให้ตรงกับข้อเสนอ
- [ ] สแกนแบบฟอร์มและแนบท้ายไฟล์ตามคำแนะนำในระบบรับสมัคร

## จริยธรรมและความปลอดภัย

- โครงการฉบับนี้เป็นการจำลองด้วยซอฟต์แวร์ และระบุว่าไม่ใช้มนุษย์ สัตว์มีกระดูกสันหลัง ตัวอย่างชีวภาพ สารเคมี หรืออุปกรณ์ทดลองอันตราย
- หากขอบเขตจริงเปลี่ยนจนเกี่ยวข้องกับคนหรือสัตว์ ต้องหยุดและยื่นแบบฟอร์มจริยธรรมที่เกี่ยวข้องก่อนเริ่มส่วนนั้น

## ไฟล์อัปโหลด

- [ ] ใช้ PDF ที่เปิดอ่านได้และมีขนาดไม่เกิน 20 MB
- [ ] ตรวจลำดับหน้า: หน้าปก SIMS ที่ลงนามแล้ว → เนื้อหาข้อเสนอ → แบบฟอร์มที่ต้องแนบท้าย
- [ ] ไม่อัปโหลดไฟล์ชื่อ `รอลายเซ็น` เป็นฉบับสุดท้ายจนกว่าจะลงนามและแนบแบบฟอร์มครบ
- [ ] ดาวน์โหลดไฟล์กลับจากระบบหลังอัปโหลดและเปิดตรวจซ้ำก่อนหมดเวลา
