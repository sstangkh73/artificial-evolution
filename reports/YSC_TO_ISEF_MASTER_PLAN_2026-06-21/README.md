# YSC to ISEF Master Plan

This folder is the competition-facing strategy package for the `artificial-evolution` project,
prepared on `2026-06-21`.

Purpose:

- define how to position the project for `YSC`
- identify what must be shown to win or place strongly at `YSC`
- map the strongest route from `YSC` to `ISEF`

Contents:

- `01_ysc_positioning.md` — how the project should be framed for YSC right now
- `02_ysc_competition_strategy.md` — what to emphasize, what to avoid, and how to handle judges
- `03_ysc_to_isef_roadmap.md` — the stepwise path from a YSC-ready project to an ISEF-credible flagship result
- `04_judge_questions_and_answers.md` — tough likely questions with recommended answer directions
- `05_competition_conclusion_max_strength.md` — earlier competition conclusion using the evolution-transition framing
- `06_self_learning_competition_framing.md` — recommended current framing centered on self-learning without labels, oracle knowledge, or hand-coded high-level strategies

Scope note:

- This package is based on the repository survey, current code, and the latest status reports already synthesized in [reports/ISEF_MASTER_PLAN_2026-06-21](/C:/artificial-evolution/reports/ISEF_MASTER_PLAN_2026-06-21).
- The strategic assumption is that the immediate goal is `YSC`, while `ISEF` remains the larger destination.
