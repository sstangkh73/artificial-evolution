# ข้อสรุปฉบับใหม่สำหรับส่งแข่ง: Agent เรียนรู้เองโดยไม่มีป้ายกำกับได้หรือไม่

Prepared: `2026-06-21`

## แกนคำถามที่ควรใช้ในการแข่งขัน

คำถามวิจัยหลักของโครงงานนี้ควรถูกตั้งให้คมที่สุดว่า:

`Agent ที่ไม่ได้รับการปักป้ายความหมายของสิ่งแวดล้อม ไม่ได้รับ oracle และไม่ได้ถูกสอนกลยุทธ์ระดับสูงล่วงหน้า สามารถเรียนรู้พฤติกรรมที่มีประโยชน์จากผลลัพธ์ตามธรรมชาติของการกระทำในโลกจำลองได้หรือไม่`

เวอร์ชันภาษาอังกฤษสำหรับใช้ใน abstract หรือสไลด์:

`Can embodied artificial agents learn useful behavior from environmental consequences without labels, oracle knowledge, or hand-coded high-level strategies?`

ประโยคนี้แข็งกว่า framing เดิมเรื่อง `stable endogenous evolution` สำหรับการแข่งขันรอบนี้ เพราะหลักฐานที่แข็งที่สุดในรายงานล่าสุดสนับสนุนเรื่องการเรียนรู้จากโลกและผลย้อนกลับทางนิเวศโดยตรง ส่วนปัญหาการส่งต่อข้ามรุ่นยังเป็นงานใหญ่ที่ต้องแก้ต่อและควรวางเป็น next frontier มากกว่าการใช้เป็น claim หลักในรอบส่งแข่ง

## ข้อสรุปหลักสำหรับใช้ในรายงานหรือบอร์ด

โครงงาน `Artificial Evolution` ศึกษาว่า agent ประดิษฐ์ที่อยู่ในโลกจำลองที่มีทรัพยากร พลังงาน และวงจรนิเวศจริง จะสามารถเรียนรู้พฤติกรรมที่มีประโยชน์ได้เองหรือไม่ เมื่อผู้วิจัยไม่ได้ปักป้ายบอกความหมายของสิ่งแวดล้อม ไม่ได้ให้ oracle ว่าสิ่งใดคือเมล็ดหรือพื้นที่ดี และไม่ได้สอนกลยุทธ์ระดับสูง เช่น การทำฟาร์ม การเลือกพื้นที่ หรือการกลับไปหาแหล่งอาหารล่วงหน้า ระบบถูกออกแบบให้ agent ต้องรับผลจากการกระทำของตนเองผ่านข้อจำกัดของโลก เช่น การกินอาหาร การเคลื่อนที่ ความหิว ตำแหน่ง และวงจรพืช แทนการรับคำตอบสำเร็จรูปจากผู้สร้าง

ผลการทดลองปัจจุบันแสดงให้เห็นว่า agent สามารถเกิดพฤติกรรมที่มีประโยชน์จากประสบการณ์ในโลกได้จริงในระดับที่วัดผลได้ โลกจำลองผ่าน `ecology gate` โดยสร้างวงจร `seed -> plant -> fruit -> consumed` ได้ใน `5/5 seeds` ภายใต้เงื่อนไขที่กำหนด ทำให้ระบบมีสัญญาณนิเวศที่เพียงพอสำหรับการทดสอบการเรียนรู้ จากนั้นในการทดลอง `Reward-Place Learning` agent ที่เคยกินอาหารจากพืชสามารถกลับไปยังบริเวณที่เคยได้รับอาหารได้สูงกว่าความบังเอิญอย่างมาก โดยมีค่าเฉลี่ย `return lift 41.7x` เมื่อเทียบกับ random-position baseline และในการทดลอง `Seed Causality / Proto-Farming Substrate` เมล็ดที่ถูกย้ายโดย agent สามารถกลับเข้าสู่วงจรพืชและกลายเป็นอาหารในภายหลังได้จริง โดยมีค่าเฉลี่ย `moved/control lift 1.40x` ผลทั้งสามส่วนนี้สนับสนุนข้อสรุปว่า agent ไม่ได้เพียงเดินสุ่มในโลก แต่สามารถสร้างความสัมพันธ์ระหว่างประสบการณ์ ตำแหน่ง อาหาร และผลลัพธ์เชิงนิเวศได้โดยไม่ต้องได้รับป้ายกำกับหรือคำสั่งระดับแนวคิดจากผู้ทดลอง

ความสำคัญของงานนี้อยู่ที่การแยกให้ชัดระหว่าง “การดูเหมือนฉลาด” กับ “การเกิดพฤติกรรมที่มีหลักฐานรองรับ” โครงงานไม่ได้อ้างว่า agent เข้าใจการปลูกพืชแบบมนุษย์ หรือมีเจตนาทำฟาร์มเต็มรูปแบบ แต่แสดงหลักฐานที่แคบและแข็งกว่า คือ agent สามารถเรียนรู้ตำแหน่งที่ให้ผลตอบแทนจากประสบการณ์ และการกระทำของ agent สามารถสร้างผลย้อนกลับเชิงนิเวศที่ตรวจสอบได้ในภายหลัง นอกจากนี้ การทดลองระยะต่อมายังช่วยจำกัดขอบเขตของข้อสรุปให้แม่นขึ้น เช่น ผล Phase 4 ทำให้ต้องลด claim เรื่อง managed patch และผล Phase 5 แสดงว่า site selection ยังถูก confound ด้วย hunger state ซึ่งเป็นการทำ falsification ที่ช่วยให้โครงงานน่าเชื่อถือขึ้น เพราะผู้วิจัยไม่ได้นำทุกพฤติกรรมที่ดูน่าสนใจมาอ้างเป็นความเข้าใจของ agent โดยไม่มีหลักฐาน

ดังนั้นข้อค้นพบหลักของโครงงานในสถานะปัจจุบันคือ: ภายใต้โลกจำลองที่มีข้อจำกัดทางพลังงานและนิเวศวิทยา agent สามารถเรียนรู้พฤติกรรมที่มีประโยชน์จากผลลัพธ์ของการปฏิสัมพันธ์กับโลกได้ โดยไม่ต้องมีป้ายกำกับ ความหมายสำเร็จรูป หรือ oracle คอยบอกคำตอบ สิ่งนี้ทำให้โครงงานยืนได้ในฐานะงานวิจัย artificial life ที่ศึกษากลไกการเรียนรู้จากโลกจริงของ agent อย่างเป็นระบบ และวางรากฐานให้คำถามระยะถัดไป คือการทำให้พฤติกรรมที่เรียนรู้ได้เหล่านี้ส่งต่อ ขยายผล และถูกคัดเลือกข้ามรุ่นในอนาคต

## Claim ที่อ้างได้อย่างมั่นใจ

- อ้างได้ว่าโลกจำลองมี ecological substrate ที่ทำงานได้จริงในเงื่อนไขทดลอง เพราะ Phase 1 ผ่าน `5/5 seeds` และมี `plant matured`, `plant fruited`, และ `plant food consumed`
- อ้างได้ว่า agent แสดง reward-place learning เพราะ Phase 2 ผ่าน `3/3 seeds` และมีค่าเฉลี่ย `return lift 41.7x` เมื่อเทียบกับ random-position baseline
- อ้างได้ว่าการกระทำของ agent ส่งผลต่อวงจรนิเวศแบบ delayed consequence ได้ เพราะ Phase 3 ผ่าน `3/3 seeds` และมีค่าเฉลี่ย `moved/control lift 1.40x`
- อ้างได้ว่างานนี้ไม่ได้ใช้ oracle หรือ semantic farming instruction เป็น claim หลัก เพราะรายงานระบุชัดว่าไม่ได้บอก agent ว่าเมล็ดคืออะไรหรือสอนความหมายของการทำฟาร์ม
- อ้างได้ว่าโครงงานมีความเข้มแข็งเชิงวิทยาศาสตร์ เพราะมีการทำ falsification และลด claim เมื่อ evidence ไม่พอ เช่น Phase 4 และ Phase 5

## Claim ที่ไม่ควรพูดเกิน

- อย่าพูดว่า agent เข้าใจการปลูกพืชแบบมนุษย์
- อย่าพูดว่า agent มี intentional farming เต็มรูปแบบ
- อย่าพูดว่าเกิด open-ended evolution แล้ว
- อย่าพูดว่าแก้ปัญหาการส่งต่อข้ามรุ่นแล้ว
- อย่าพูดว่าไม่มี reward ใด ๆ เลย เพราะอาหารและความอยู่รอดยังเป็น natural consequence ของโลก คำที่แม่นกว่าคือ `ไม่มี labeled reward`, `ไม่มี oracle`, `ไม่มี hand-coded high-level strategy`

## เวอร์ชันสั้นสำหรับพูดกับกรรมการ

โครงงานนี้ไม่ได้ถามว่าเราจะเขียนกฎให้ agent ดูฉลาดได้แค่ไหน แต่ถามว่า agent จะเรียนรู้พฤติกรรมที่มีประโยชน์เองจากโลกได้หรือไม่ เมื่อเราไม่ปักป้ายความหมาย ไม่ให้ oracle และไม่สอนกลยุทธ์ระดับสูงล่วงหน้า ผลตอนนี้พบว่าโลกจำลองสร้างวงจรพืชได้จริงใน `5/5 seeds`, agent กลับไปยังตำแหน่งอาหารได้สูงกว่าความบังเอิญเฉลี่ย `41.7 เท่า`, และเมล็ดที่ agent ย้ายสามารถกลับเข้าสู่วงจรพืชและกลายเป็นอาหารได้จริงด้วยค่า `moved/control lift 1.40 เท่า` ดังนั้นข้อสรุปหลักคือ agent สามารถเรียนรู้ความสัมพันธ์ที่มีประโยชน์จากผลลัพธ์ของการปฏิสัมพันธ์กับโลกได้ โดยไม่ต้องมีป้ายกำกับหรือความหมายสำเร็จรูปจากผู้สร้าง

## ทำไม framing นี้มีโอกาสชนะสูงกว่า

กรอบนี้ทำให้โครงงานตอบคำถามเดียวที่กรรมการเข้าใจได้เร็ว: `agent เรียนรู้เองได้จริงแค่ไหนเมื่อไม่มีคนบอกคำตอบ` ซึ่งชัดกว่าและแข่งขันได้ดีกว่าการวาง claim หลักไว้ที่การเกิดวิวัฒนาการข้ามรุ่น เพราะผลข้ามรุ่นยังติดปัญหาใหญ่เรื่อง population sustainability และ reproduction dynamics ในรายงานล่าสุด ขณะเดียวกัน framing นี้ยังใช้หลักฐานที่แข็งที่สุดของโครงงานโดยตรง ได้แก่ Phase 1-3 และเปลี่ยนผล Phase 4-5 จากจุดอ่อนให้เป็นเครื่องยืนยันความซื่อสัตย์ของวิธีวิจัย: เมื่อหลักฐานไม่พอ ผู้วิจัยลด claim และระบุ confound อย่างชัดเจน

สำหรับสนาม `YSC`, framing นี้ทำให้งานมีทั้งความง่ายในการสื่อสารและความลึกทางวิทยาศาสตร์:

- คำถามจำง่าย: agent เรียนรู้เองโดยไม่มีป้ายกำกับได้ไหม
- วิธีมีความลึก: embodied world, ecology, memory, energy, plant lifecycle
- ผลวัดได้: `5/5 seeds`, `41.7x return lift`, `1.40x moved/control lift`
- ขอบเขตซื่อสัตย์: ไม่อ้าง intentional farming หรือ evolution เต็มรูปแบบ
- ทางไปต่อชัด: จาก self-learning ไปสู่ cross-generation learning และ endogenous evolution

## คำแนะนำการใช้จริงในการแข่งขัน

ให้วาง `self-learning without labels/oracle` เป็นคำถามหลักของรายงานและการนำเสนอ ส่วนปัญหา reproduction, generation transfer และ endogenous evolution ให้ย้ายไปอยู่ในหมวด `Future Work / Next Frontier` โดยพูดว่าเป็นขั้นถัดไปหลังจากพิสูจน์แล้วว่า agent สามารถเรียนรู้ความสัมพันธ์ที่มีประโยชน์จากโลกได้ในระดับพฤติกรรมเดี่ยวและ ecological feedback เบื้องต้นแล้ว
