# ISEF Master Plan Package

This folder is a project-wide synthesis for the `artificial-evolution` repository,
prepared on `2026-06-21` with the project's stated top-level goal of reaching `ISEF`.

Contents:

- `01_project_synthesis.md` — what the project is, what is implemented, and what the strongest current claims are
- `02_repository_inventory.md` — a practical map of the repository, evidence sources, and what to trust first
- `03_isef_roadmap.md` — an `ISEF-first` plan focused on novelty, experimental rigor, judging criteria, and near-term execution

Scope note:

- The repository contains thousands of generated data artifacts, logs, dashboards, and publication bundles.
- This package is based on a broad repository survey plus close reading of the main code, docs, reports, and tests that currently define the project's scientific state.
- It is meant to be the working launch point for future research, writing, and competition preparation.
